# Premium range returns

## 1. What counts as premium

The premium range is every item listed with the Premium badge, launched in August 2026. It includes copper cookware, hand-thrown ceramics and the knife collection.

## 2. The premium return window

Premium range items can be returned within 14 days of delivery, not 30.

## 3. Restocking fee

A restocking fee of 10 % of the item price is deducted from the refund for any premium item returned unboxed. Premium items returned sealed in their original packaging carry no fee.

## 4. Faulty premium items

If a premium item is faulty, the fault rules in the warranty policy apply instead, with no restocking fee.
